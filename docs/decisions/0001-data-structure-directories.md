# 0001. データ構造のディレクトリを増やさない

## 決定

データ構造は `lib/data_structure/` に置き、**ファミリ専用ディレクトリを新設しない**。
既存の例外は `segtree/`・`heap/`・`persistent_ds/` の 3 つだけとする。

## 理由

バリアントが増えたからといってディレクトリを昇格・降格させると、使うたびに
「このファミリには専用ディレクトリがあったか」を思い出す必要が生じる。

分けてよいのは**配置が見た目で判別でき、思い出す必要のない軸**だけ。既存の例外はこの条件を満たす。

- `segtree/` — セグメント木系であることが名前から明らか。
- `heap/` — ヒープであることが名前から明らか。
- `persistent_ds/` — 永続・部分永続版は名前に `persistent` が入るものすべて、と機械的に判別できる。

## 影響

新しいデータ構造は原則 `lib/data_structure/` 直下に置く。同種の実装が増えても
ディレクトリは切らない。現行の規則は
[current/overview.md](../current/overview.md)。
