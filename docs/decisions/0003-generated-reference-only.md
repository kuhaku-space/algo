# 0003. リファレンスはヘッダコメントだけから生成する

## 決定

公開リファレンス（cpprefjp 風）は**ヘッダの `///` コメントだけ**から生成し、`reference/` 配下に
手書きの Markdown ページを置かない。生成物は Git 管理外の `docs/generated/` に出す。

## 理由

説明が実装と別ファイルにあると、実装を変えたときに片方だけ古くなる。ヘッダのコメントを
唯一の情報源にすれば、説明はコードの隣にあり、`mise run docs-check` が網羅率・例のコンパイルと
実行・リンクを機械的に検査できる。

生成物をコミットしないのは、差分が実装の変更に埋もれてレビューの邪魔になるため。
CI が検査時とサイト構築時に毎回生成する。

## 影響

- 文章を直すときはヘッダを編集する。ページの体裁を変えたいときは `tools/reference/` を編集する。
- `docs/` 直下の開発ドキュメント（この文書や執筆ガイド）は手書きでよい。これらもサイトに載る。
- 現行の規則は [current/documentation.md](../current/documentation.md)、
  書き方は [reference_style.md](../reference_style.md)。
